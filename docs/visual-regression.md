## Differences found during the migration and how they were resolved

| # | Where | Symptom | Class | Cause | Resolution |
|---|---|---|---|---|---|
| 1 | Profiles | Contact-details list unstyled | B implementation bug | Essential Blocks' frontend stylesheet (`assets/admin/editor/editor.css`, misleading name) had been dropped as "admin" CSS | Kept |
| 2 | Investigación (all widths) | Columns 75/25 % instead of the original proportions; page 1 243 px shorter | B | CSS taken from the un-bundled stylesheets, which were edited after WP Fastest Cache built the bundles that visitors actually receive | CSS re-extracted from the served bundles |
| 3 | News posts | Different sidebar list | H content mismatch | A published post is hidden from all listings on the original site | `"listed": false` in its JSON |
| 4 | Tag/category archives (desktop) | Header 121 px taller locally | F responsive/layout | Those archives do not use the transparent header on the original | Body classes per archive type fixed |
| 5 | Archives and /personaldia/ at 390 px | Header 62 px shorter | B | Pages without transparent header use a different logo (SVG, 90 px high on mobile) | `site.logoOpaqueHeader` |
| 6 | Presentación hero | Missing moving circuit background | G JavaScript behaviour | Background video injected by the jQuery "Video Background" plugin | Re-implemented in `site.js` (local MP4, poster on mobile) |
| 7 | Two Larrañaga posts | Different banner image | C asset / H | The banner uses the unedited image while listings use the cropped featured image | `bannerImage` field |
| 8 | Post "Oferta de beca…" | Banner showed a broken image | C | JSON-LD "image" of that post is a PDF | Removed (the original has no featured image) |
| 9 | Personnel page at 390 px, Investigación at 390 px | 0.17–0.19 % residual | A harmless | Font Awesome glyph rasterisation / font loading order and anti-aliasing of text over a photographic background; the same icon renders identically on other profiles | Accepted |
| 10 | Contact page | 0.02–0.06 % | A | Anti-aliasing around the hidden map iframe and the photo edges | Accepted |

Not covered by screenshots but checked by the functional tests or manually: mobile menu open state, sticky header,
dropdowns, tab switching, Top Stories pagination, video pop-up (all compared side by side with the live site).
